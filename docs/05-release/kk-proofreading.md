Алматы — Алматы маңындағы су айдындары; Стоянки с ночёвкой — Түнеуге болатын тұрақтар; Родники —
Бұлақтар; Что посмотреть по дороге — Жол бойындағы көрікті жерлер; Платники и снасти — Ақылы
тоғандар мен балық аулау құралдары.
