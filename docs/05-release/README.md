**Каждое обновление** (Claude или владелец, всё — из `main`):

1. Поднять `MARKETING_VERSION` в `ios/project.yml`: 1.0.1 — исправления, 1.1.0 — новые функции. Без
   этого App Store Connect не создаст новую версию. Вместе с ним — **«Что нового в этой версии»**:
   `appstore/listing/ru/whats_new/<версия>.txt` и `appstore/listing/en-US/whats_new/<версия>.txt` (до
   4000 символов; у обновлений обязательно). Заметки для тестировщиков —
   `appstore/testflight/what_to_test.<язык>.txt`.
2. Actions → **TestFlight** → Run workflow; затем **TestFlight info** с номером сборки и `submit` —
   сборка уходит тестировщикам (бета-проверка новой версии — до суток-двух).
3. Если экраны заметно изменились — **Screenshots** с галочкой «upload».
4. Actions → **App Store release** с номером сборки: тексты страницы и «Что нового», рейтинг, данные
   для проверки, сборка — к версии, **поэтапный выпуск** (7 дней). В конце workflow печатает, что
   осталось (например, нет файла «Что нового»).
5. **Отправка на проверку** — владелец: App Store Connect → версия → Add for Review → Submit. Если есть
   событие App Store к этой версии, можно одним шагом: Actions → **App Store featuring** с `event`,
   `submit` и `with_version` (по просьбе владельца это делает и Claude). Выпуск после одобрения —
   кнопка Release или Actions → **App Store release** с галочкой `release`. Выпуск —
   ручной: после одобрения нажать Release, дальше обновление само доходит до всех за 7 дней
   (приостановить или выпустить сразу всем — на странице версии).

Сайт ведёт в App Store сам (`APP_STORE_ID` в `.github/scripts/build_site.py`) — для обновлений
ничего менять не нужно.

|---|--------|---------|
| 1 | Когда запускаемся | **Как только всё готово**, не ждём мая; пользователей набираем органически |
| 2 | Страны | **Только Казахстан** — и карта на весь Казахстан (R2). ЕС — не раньше, чем будет статус трейдера по DSA |
| 3 | Домен | **Пока без домена**: сайт и ссылки остаются на `dkicekeeper.github.io/Dalada`, почта поддержки — текущая |

| 5 | Подтверждение телефона | **Отложено**: платная регистрация по номеру не нужна. Друзья из контактов — позже и без номера в аккаунте (см. ниже) |
| 8 | Иконка | **B — поплавок** |

Остаются открытыми:

| # | Вопрос | Варианты | Рекомендую |
|---|--------|----------|------------|
| 7 | Хранение данных в РК | Закон РК «О персональных данных и их защите» требует хранить базу с данными граждан в РК; 1.0 вышла, данные пользователей — во Франкфурте. | 9 | Фото для скриншотов | Свои / амбассадоров с письменным разрешением | Амбассадоров: настоящие уловы |
| 10 | Проверка казахского носителем | Знакомый носитель / переводчик | Носитель из целевой аудитории (рыбак) |

**Друзья из контактов без номера в аккаунте.** Если номер в профиле не подтверждён, любой может
вписать чужой номер и показаться друзьям того человека «знакомым из контактов» — так легко выманить
доступ к записям «для друзей». Поэтому без подтверждения номера — только безопасные варианты:
«Пригласить из контактов» (ссылка-приглашение в WhatsApp или SMS выбранному человеку) и поиск по
адресам e-mail из контактов, подтверждённым при входе через Google. Сопоставление по номерам — только
вместе с подтверждением номера, если к нему вернёмся.

## Иконка

Временная иконка (горы, солнце, волны) — общая, тонкие волны пропадают в маленьком размере, и
она не говорит «рыбалка». Новая должна:

- узнаваться в 40 px на домашнем экране — один крупный силуэт, без текста и мелких деталей;
- говорить «на природе» (далада) и «рыбалка», без привязки только к рыбалке;

## Страница App Store

Основной язык — **русский**; второй — **английский (США)**. Казахского в App Store Connect нет
([список языков Apple](https://developer.apple.com/help/app-store-connect/reference/app-information/app-store-localizations/)),
а язык витрины Казахстана по умолчанию — английский (Великобритания). Казахские слова кладём в
ключевые слова. **Проверено на живой странице (2026-11-01):** на устройстве с русским языком витрина
Казахстана показывает русскую страницу, по умолчанию (английский, Великобритания) — страницу en-US.
Добавлять английский (Великобритания) не нужно.

Тексты лежат в [`appstore/listing/`](../../appstore/listing/) — `<локаль>/name.txt` (30 символов),
`subtitle.txt` (30), `keywords.txt` (100), `promotional_text.txt` (170, меняется без проверки),
`description.txt` (4000) для `ru` и `en-US`, «Что нового» обновлений — `whats_new/<версия>.txt` (4000),
общие ссылки — `support_url.txt`, `marketing_url.txt`, `privacy_policy_url.txt`. Категории: основная — «Спорт», дополнительная — «Путешествия».

Workflow **App Store page** (`appstore/listing.py`): на любой ветке проверяет длины, из `main` сам
отправляет тексты в App Store Connect (версию с номером `MARKETING_VERSION` создаёт, если её нет;
пока версия на проверке или уже в App Store — ничего не меняет). Сборку к версии не привязывает и на
проверку не отправляет. Описание написано под выход с картой всего Казахстана.
