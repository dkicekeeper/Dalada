# M34. Карта Казахстана

> 2026-10-09. Статус: **в работе**. Из решения владельца ([релиз, решение 2](../05-release/README.md#решения)):
> витрина App Store — только Казахстан, значит, карта и данные — на всю страну, а не только
> Алматинская область и Жетісу.

## Что меняется для человека

- Карта, рельеф и «Карты без сети» — по всему Казахстану: Боровое, Баянаул, Бухтарма и Алтай,
  Зайсан, Балхаш, Мангистау, горы Туркестанской и Жамбылской областей, реки Урал, Иртыш, Ишим.
- Места редакции (водоёмы, стоянки, родники, базы) — по всей стране, из OpenStreetMap.
- Нацпарки и заповедники — по всей стране; погранзона — вдоль всех границ.
- Запреты на лов — по бассейнам из того же приказа, что и сейчас; где правил ещё нет —
  честная подпись «Правила для этой области ещё не внесены».

## Шаги

| 4 | **Места редакции** из OpenStreetMap по всей стране — по правилам отбора, а не вручную по одному | `supabase/data/places` | — |
| 5 | **Нацпарки и заповедники** по всей стране, погранзона вдоль всех границ | `supabase/data/areas` | — |

| 7 | **Тексты**: приложение, сайт, App Store — «Казахстан» вместо «Алматинская область и Жетісу» | строки, `docs/public`, `appstore/listing` | — |

## Объём

| | Сейчас | Казахстан |
|---|--------|-----------|
| Тайлов подложки (масштабы 0–14, по прямоугольнику) | ~185 тыс. | ~2,6 млн (часть — пустые за границей, Planetiler их не пишет) |
| Высоты Copernicus DEM (1° × 1°) | ~50 | ~130 (горные районы) |

Первая загрузка ~2 млн тайлов в R2 — больше миллиона записей в месяц (сверх бесплатного лимита R2 —
$4,5 за миллион, разово); дальше раз в месяц уходят только изменившиеся тайлы.
