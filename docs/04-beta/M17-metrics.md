# M17. Метрики продукта без слежки

> Статус: **готово на сервере** (сборка приложения не нужна). Из плана (`docs/02-plan/README.md`,
> «Метрики»): North Star, здоровье контента, удержание W1 / W4, поездки за месяц, воронка новых
> пользователей.

## Почему без событий

Политика конфиденциальности обещает: «не используем аналитику поведения». Поэтому приложение
ничего дополнительно не отправляет — ни экранов, ни нажатий, ни идентификаторов устройства. Метрики
считаются по тому, что человек и так сохраняет: чекины, уловы, поездки, отзывы, друзья, места.
Ответ — только суммы и доли, без координат, имён и идентификаторов.

Аналитика событий (TelemetryDeck или своя таблица, решение D12 в архитектуре) — только по решению
владельца продукта: она требует поправить политику и ярлык приватности в App Store Connect.

## Как смотреть

Supabase Studio → SQL Editor (клиенту функции недоступны):

```sql
select * from private.metrics_weekly();          -- 12 недель: North Star и активность
select * from private.metrics_cohorts();         -- когорты по неделе регистрации: воронка, W1, W4
select * from private.metrics_content_health();  -- доля публичных мест со свежим отчётом
select * from private.metrics_monthly_trips();   -- 6 месяцев: доля активных с 2+ поездками
```

Число недель или месяцев — параметром: `private.metrics_weekly(26)`. Здоровье контента на дату —
`private.metrics_content_health('2027-06-15')`.

| Метрика | Где | Как считается |
|---------|-----|---------------|
| **North Star** — активные за неделю | `metrics_weekly.active_users` | Хотя бы один чекин (он же отчёт о месте), улов, поездка или отзыв за неделю |
| Новые пользователи, новые пары друзей | `metrics_weekly.new_users`, `new_friends` | По дате регистрации и дружбы |
| Воронка новых | `metrics_cohorts.activated`, `with_friend` | Первая активность / первый друг в первые 7 дней после регистрации |
| Удержание W1 / W4 | `metrics_cohorts.w1`, `w4`, доли | Активны на 1-й / 4-й неделе после недели регистрации; пусто, пока та неделя не закончилась |
| Здоровье контента | `metrics_content_health` | Публичные опубликованные места с чекином за 7 дней: `fresh_public` — публичный чекин (видит любой), `fresh_any` — любой видимости, и для друзей, и личный |
| 2+ поездки за месяц | `metrics_monthly_trips.share` | Доля активных за месяц, у кого две поездки и больше |

Неделя — с понедельника, месяц — календарный, всё по времени Алматы. Служебные аккаунты (редакция
`@dalada` и аккаунт для проверки Apple) и удалённое не считаются. Активность — по времени, когда
запись дошла до сервера (без сети — когда телефон её отправил).

## Чего пока нет

- **Рост и K-фактор** (доля пришедших по приглашению или шарингу): в базе нет, откуда пришёл
  человек. Нужны ссылки-приглашения с кодом — отдельная задача; до тех пор видно только новые пары
  друзей и долю новых с другом в первую неделю.
- **Метрики вкладок** (открытия экранов, поиск, фильтры) — только с аналитикой событий, см. выше.

## Как устроено

Миграция `…_metrics.sql`: функции в закрытой схеме `private`, права на выполнение отозваны у
`anon` и `authenticated`. Тест `34_metrics.test.sql` — недели, когорты, здоровье контента, поездки за
месяц, исключение служебных аккаунтов и удалённого, закрытый доступ.
