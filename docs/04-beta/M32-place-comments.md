# M32. Заметки в непубличных местах

> 2026-10-06. Из плана ([03-places.md](../02-plan/03-places.md)): «Дневник приватного места… в 1.1 —
> комментарии для тех, кто видит место». Сборка 137.

## Что делает

- В карточке места «только я», «друзья» или «близкие» — вкладка **«Заметки»**:
  - «только я» — дневник места: «Видите только вы — клёв, дорога, что взять в следующий раз»;
  - «друзья» / «близкие» — разговор с теми, кто видит место, без отзывов для всех.
- Заметки — те же комментарии, что у поездок и отчётов: написать, удалить свою; владелец места
  удаляет любые; на заметку можно пожаловаться. Владельцу места — уведомление «Новый комментарий»
  (нажатие открывает заметки).
- У публичных мест вкладки нет: там отзывы и обсуждения. Реакций («респектов») к месту нет.

## Как устроено

- `20261121090000_place_comment_kind.sql` — `reaction_target` += `place`;
  `20261121100000_place_comments.sql` — комментарии к месту, видимость (только непубличное, по
  видимости места и блокировкам), владелец; реакции к месту запрещены ограничением.
- iOS: `ReactionTarget.place`, вкладка «Заметки» (`PlaceNotesSection`), ссылка из уведомления
  `dalada://comments/place/<id>`.
- Тесты: pgTAP `55_place_comments` (10), Deno `message_test.ts`, `PushTests`.
