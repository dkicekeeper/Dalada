# Места редакции

Места, которые Dalada показывает всем с первого дня, — от служебного аккаунта редакции **@dalada**
(`private.editorial_id()`, миграция `…_editorial.sql`). Войти в него нельзя; в карточке такого места
приложение пишет «Редакция Dalada», а у мест из OpenStreetMap — «Данные: © участники OpenStreetMap».

| Файл | Что |
|------|-----|
| `places.csv` | **Все места редакции** — единственный источник. Правки — здесь |
| `place_info.csv` | Сведения места: рыба, подъезд, способы ловли, удобства, особенности — с источником |
| `places.py` | Проверка таблиц, импорт из Google My Maps и CSV, сборка миграции |
| `osm_candidates.csv` | Кандидаты из OpenStreetMap с решением: `yes` — взято, `?` — посмотреть, `no` — нет |
| `wikidata.csv` | Элемент Wikidata, найденный по координатам (до 8 км) и названию, — у мест, где в OSM ссылки на Wikidata нет. Из его статей в Википедии написаны описания (волна 7б), по нему `photos.py` ищет изображение P18, категорию Commons P373 и снимки «изображено: элемент» |
| `fetch_osm.py` | Обновить кандидатов из OpenStreetMap (решения в файле сохраняются) |

## Колонки places.csv

| Колонка | Что |
|---------|-----|
| `id` | UUID места. Не меняйте — по нему миграция находит место |
| `type` | `fishing_spot` точка ловли, `water_body` водоём, `campsite` стоянка, `paid_pond` платник, `base` база отдыха, `parking` съезд/парковка, `spring` родник, `tackle_shop` снасти, `landmark` достопримечательность |
| `name` | Название, до 80 символов |
| `lat`, `lon` | Широта и долгота (43.353722, 78.505530) — в Казахстане (с M34) |
| `access_lat`, `access_lon` | Точка подъезда (необязательно), не дальше 20 км |
| `description` | Описание, до 2000 символов (необязательно) |
| `source` | Откуда: `osm:w123` — OpenStreetMap, иначе — редакция (например, `import:my_map.kml`) |

Что писать в описании и откуда брать факты — [план наполнения](../../../docs/05-release/content.md)
(аудит, источники и лицензии, очередь волн).

## Сведения места (place_info.csv)

Блок «Сведения» в карточке места (`places.attributes`, ключи — как в `DaladaCore/PlaceInfo.swift`).
Миграция мест пишет `attributes` целиком, поэтому правки в Studio потеряются — сведения правим здесь.
Строка — одно место; списки — через «;».

| Колонка | Что |
|---------|-----|
| `id`, `name` | Место из `places.csv` (название сверяется — защита от строки не на том месте) |
| `species` | Рыба: id из `fish_species` (`pike;zander;bream`) |
| `access` | Подъезд: `asphalt`, `dirt`, `offroad`, `foot`, `boat` |
| `fee` | `free` или `paid`; при `paid` — `price_kzt` (тенге), `price_unit` (`entry`, `day`, `hour`, `kg`) |
| `contact` | Телефон или сайт, до 100 символов |
| `methods` | Как ловят: `shore`, `boat`, `spinning`, `feeder`, `float`, `fly`, `bottom`, `ice` |
| `amenities` | `parking`, `toilet`, `shade`, `tent`, `fireplace`, `drinking_water`, `shop`, `boat_rental` |
| `signal` | Связь: `none`, `weak`, `good` |
| `months` | Лучшие месяцы: `5;6;9` |
| `features` | Особенности: размеры, глубины, дно, течение — до 1000 символов |
| `sources` | **Обязательно**: ссылки на источники через «;» |

После правки — `places.py migration`, как и для `places.csv`.

Места редакции всегда публичные и точные. Не добавляйте «секретные» места рыбаков — только
общеизвестные: водоёмы, платники, базы, стоянки, родники, магазины.

## Как добавить места

**Google My Maps** (удобно с телефона): карта, слои по типам — «Точки ловли», «Водоёмы»,
«Стоянки», «Платники», «Базы», «Съезды», «Родники», «Снасти», «Достопримечательности» (достаточно
части слова, на русском, казахском или английском). Меню карты → «Экспорт в KML/KMZ», затем:

```bash
python3 supabase/data/places/places.py import ~/Downloads/map.kmz
python3 supabase/data/places/places.py import extra.kml --type campsite   # слой без понятного названия
```

**Таблица** (Google Таблицы → Скачать → CSV) с колонками `type,name,lat,lon` (и при желании
`description,access_lat,access_lon`):

```bash
python3 supabase/data/places/places.py import new_places.csv
```

**Из OpenStreetMap**: в `osm_candidates.csv` поставьте `yes` нужным строкам (ссылка `link` открывает
объект на карте OSM), затем `places.py import supabase/data/places/osm_candidates.csv` — уже
добавленные пропускаются. `fetch_osm.py` решает сам: `yes` — водоёмы с названием, родники, водопады,
рыболовные магазины; `no` — без названия, номер вместо названия, солёные озёра (сор, тұз, ащы —
кроме водохранилищ), колодцы и скважины; `?` — базы, стоянки, пруды, карьеры, моря. Водоёмы без типа
(`natural=water` без `water=…` — так размечены и крупные водохранилища) идут с `?`; протоки, заливы, участки
рек и солёные по тегу `salt` — `no`.

Импорт пропускает повторы (то же место того же типа ближе 300 м) и пишет новые строки в
`places.csv`. Названия и описания после импорта можно поправить прямо в таблице.

## Как выкатить

```bash
python3 supabase/data/places/places.py migration   # новая миграция …_editorial_places.sql
python3 supabase/data/places/places.py check       # то же проверяет CI
```

Миграция добавляет новые места, обновляет изменённые и скрывает (`deleted_at`) те, что убраны из
таблицы. Скрытие и статус, поставленные модератором в Studio, она не трогает. После `main`
миграцию применяет GitHub-интеграция Supabase — места появятся в приложении сразу. CI падает, если
`places.csv` изменена, а миграция не собрана.

## Фото мест (M14)

Фото мест редакции — с [Wikimedia Commons](https://commons.wikimedia.org), только под свободными
лицензиями (CC0, CC BY, CC BY-SA, общественное достояние). Под фото приложение показывает автора,
лицензию (ссылкой) и ссылку на файл на Commons — это условие лицензий.

| Файл | Что |
|------|-----|
| `photos.csv` | **Принятые фото** — единственный источник: место, файл Commons, автор, лицензия, размер, порядок |
| `photo_candidates.csv` | Кандидаты: найденные рядом с местом и по тегам OSM (`wikimedia_commons`, `image`, `wikidata` — снимки с этим элементом и его изображение P18 и категория Commons P373; элемент — из OSM или из `wikidata.csv`); `include` — номер по порядку (1 — обложка) или `yes` взять, `no` нет |
| `photo_searched.txt` | Места, у которых уже искали (`candidates --missing` их пропускает) |
| `photos.py` | Поиск кандидатов, перенос принятых в `photos.csv`, сборка миграции, скачивание файлов для R2 |

Из облачного контейнера Claude API Commons отвечает 429 — там кандидатов ищет workflow **Photo
candidates** (Actions → Run workflow на рабочей ветке): пусто — места без фото, которые ещё не искали
(`photo_searched.txt`), или id мест через запятую; результат он коммитит в ту же ветку. Листы превью
после `git pull` — `photos.py sheets /tmp/sheets`.

```bash
python3 supabase/data/places/photos.py candidates --sheets /tmp/sheets   # кандидаты + листы превью
# в photo_candidates.csv: include — 1, 2, 3… (порядок, 1 — обложка) или yes; не больше 5 фото на место
python3 supabase/data/places/photos.py accept                            # → photos.csv
python3 supabase/data/places/photos.py migration                         # → …_editorial_photos.sql
```

Порядок фото места — колонка `position` в `photos.csv` (первое — обложка в списках «Мест»). Убрать фото —
удалить строку и собрать миграцию. Файлы на R2 (`photos/places/<id>.jpg` и `_thumb.jpg`) копирует
workflow **Editorial photos** после изменения `photos.csv` в `main`; CI проверяет, что миграция
собрана.

## Первая выборка (M6e)

165 мест из OpenStreetMap (данные на 30.09.2026): 86 водоёмов (озёра и водохранилища с названием,
без технических и безымянных), 23 водопада, 23 родника и горячих источника, 21 стоянка (поляны и
кемпинги у Алматы, Чарын, Топарские озёра), 5 мест рыбалки, 3 платника, 3 магазина снастей, база
«Рыбацкая деревня». Точка водоёма — внутри контура; описания — только из данных OSM на русском или
казахском (питьевая ли вода, адрес, часы работы).

## Вторая выборка (после беты 128)

Ещё 121 место из `?` в `osm_candidates.csv` — всего **286**: 79 баз отдыха (Алаколь — Акши и
Коктума, Чунджа с горячими источниками, Кольсай, Капшагай, Балхаш, ущелья у Алматы; без городских
санаториев и детских лагерей) и 42 стоянки и приюта в горах (хижины Букреева, Кумбель, Туйыксу и
другие, альплагеря Тау Намыс, Альпинград и Нунатак, поляны, Черкасай). Не взяты вагончики
«Казселезащиты» (служебные), стоянки с непонятными названиями и пруды.

Что стоит посмотреть редакции: оставшиеся `?` (пруды, водопады у 44° с. ш., родники без названия),
описания популярных водоёмов (что ловится, как подъехать) и точки подъезда; работают ли базы.
