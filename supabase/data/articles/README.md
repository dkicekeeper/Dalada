# Статьи и советы

Исходники статей для миграции `migrations/…_articles.sql`: по файлу на язык — `<id>.ru.md`,
`<id>.kk.md`, `<id>.en.md`; категория, порядок и дата — в `index.json`.

```
---
title: Заголовок
summary: Одна-две фразы для списка статей.
---
Текст статьи.
```

## Разметка

Приложение показывает подмножество Markdown:

| Что | Как |
|-----|-----|
| Заголовок раздела | `## Заголовок`, подраздел — `### Заголовок` |
| Абзац | Строки подряд; пустая строка — новый абзац |
| Список | `- пункт` |
| Шаги | `1. шаг` |
| Выноска (предупреждение, совет) | `> текст` |
| Внутри строки | `**жирный**`, `*курсив*`, `[ссылка](https://…)` |

Нельзя: картинки, HTML, таблицы, заголовок `#`, вложенные списки, блоки кода — `build_sql.py`
остановится с ошибкой.

## Как добавить статью

1. Файлы `<id>.ru.md`, `<id>.kk.md`, `<id>.en.md` и строка в `index.json`: категория, `sort_order`
   (меньше — выше в списке; зимние статьи — 5–9, перед «Безопасностью на льду» с 10) и дата.
2. Факты о правилах — только из первоисточников (приказ о запретах, Правила рыболовства) и так же,
   как в слое правил приложения; водоёмы «где водится» — из сведений мест (`place_info.csv`).
3. SQL: `python3 supabase/data/articles/build_sql.py <id>` — в новую миграцию
   `…_article_<id>.sql` с шапкой: о чём статья, источники правил, что казахский и английский —
   черновик на вычитку.
4. Тесты: счётчик опубликованных статей в `supabase/tests/database/14_articles.test.sql`, тесты
   порядка соседних статей и свой тест на новую (порядок, три языка, ключевые факты в тексте).
5. `supabase db reset` и `supabase test db`, PR. После слияния — workflow **Pages**: появится
   страница `…/a/<id>/` на трёх языках и строка в sitemap.

## Как поправить статью

```bash
python3 supabase/data/articles/build_sql.py > /tmp/articles.sql          # все статьи
python3 supabase/data/articles/build_sql.py camp_site > /tmp/new.sql     # только эти
```

Правка — миграцией с `update public.articles set body_ru = $md$…$md$ where id = '…'` или, для
небольшой правки, `replace(body_ru, $old$…$old$, $new$…$new$)` (уже применённые миграции не
редактируем) — и та же правка в `.md`, чтобы исходники не разошлись с базой. Черновик —
`is_published = false`: в приложении его не видно. Небольшие правки можно делать прямо в Supabase
Studio — приложение подхватит их в течение часа, но тогда перенесите их и в `.md`.

Категории: `tackle` (снасти и приманки), `knots` (узлы), `technique` (техника ловли), `cooking`
(приготовление улова), `safety` (безопасность), `rules_ethics` (правила и этика), `places_seasons`
(места и сезоны).

Казахский и английский тексты статей — черновик на вычитку носителем (список —
[docs/05-release/kk-proofreading.md](../../../docs/05-release/kk-proofreading.md)).
